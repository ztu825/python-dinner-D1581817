## 問題回答

**問題一:為什麼 `"4"` 要先轉成數字,才能用於本題的分攤計算?**

(請改成自己的話)`"4"` 是字串,只是長得像數字的文字,不能拿來做除法,否則 Python 會出現 TypeError。用 `int("4")` 轉成整數 4 之後,才能執行 `應付總額 / 4`。

**問題二:如果先扣折價券,再依剩餘餐費計算服務費,第一組的應付總額會變成多少?為什麼和題目規定的結果不同?**

(請改成自己的話)先扣折價券:1200 − 100 = 1100,服務費 = 1100 × 0.10 = 110,應付總額 = 1100 + 110 = **1,210 元**。題目規定的做法是服務費 = 1200 × 0.10 = 120,應付總額 = 1200 + 120 − 100 = **1,220 元**。差 10 元,因為服務費的計算基準不同:題目規定以原始餐費計算,先扣折價券會讓服務費的基準變少 100 元,服務費就少 100 × 0.10 = 10 元。
